Fishhawk is a workflow engine for agent-driven software changes. It defines the
stages a change moves through, enforces policy on what an agent may and may not
do, gates the work behind human approvals, and keeps a signed, append-only
record of every plan, approval, and outcome.

**Status: alpha.** The v0 control plane, runner, CLI, MCP server, and Web UI
have landed. Parts of this site are still stubs, and each one says which issue
fills it. Feature PRs are not yet being accepted while the v0 abstractions
settle.
