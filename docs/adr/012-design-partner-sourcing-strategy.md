# ADR-012: Design partner sourcing strategy

## Context

Per MVP_SPEC §13, v0 is "done" with 3–5 design partners running real work, ≥2 in compliance-conscious environments. Sourcing is open (§10 #5). With ~30 days from now to first partner, the strategy needs to be picked.

## Options

- **Personal network** — fastest, highest trust, smallest pool.
- **Cold outreach to ICP companies** — broader pool; lower hit rate; high effort.
- **Targeted content + inbound** — slower start; compounds; off-task for v0 timeline.
- **Mix** — start with network, add cold outreach by Day 30 if pool insufficient.

## Recommendation

Mix, starting with personal network. Track conversion rate; pivot if no warm partners by Day 60 (per §11 risks).
